# Apollo Labs Website Template

A Next.js marketing site template for **Apollo Labs** — a student-led organization where high school students collaborate on research projects.

## Features

- Rocket-themed loading screen (Framer Motion) — plays once per browser session
- Space-inspired dark theme
- Sections: Mission, Research pillars, Team (3 co-founders), Projects, Get involved
- Next.js 15 App Router + Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Clear `sessionStorage` key `apollo-labs-seen` to replay the loading animation.

## Build

```bash
npm run build
npm start
```

## Stack

- Next.js 15 + React 19
- Tailwind CSS v4
- Framer Motion
- Fonts: EB Garamond, Inter, Instrument Serif, JetBrains Mono
